BELIEVERS DIGITAL WEBSITE — SETUP GUIDE

FILES
- index.html: Home page
- about.html: About page
- services.html: Services overview
- contact.html: Contact page with WhatsApp enquiry form
- training.html: Training information page
- graphic-design.html: Graphic Design service detail
- website-development.html: Website Development service detail
- ai-content-creation.html: AI Content Creation service detail
- general-printing.html: General Printing service detail
- video-editing.html: Video Editing service detail
- style.css: Shared styling, mobile responsiveness and animations
- script.js: Mobile menu, scroll reveal animations and contact form behaviour
- logo.svg: Editable vector logo made with SVG code

HOW TO USE
1. Extract the ZIP file.
2. Keep all files together in one folder. Do not rename style.css, script.js or logo.svg unless you also update their references.
3. To test, open index.html in a browser. For best local testing, use a local web server.
4. To publish with GitHub Pages, upload all files to the root of your repository and enable Pages in repository Settings.
5. The contact form opens WhatsApp with the visitor's details and message prepared. The visitor still needs to press Send in WhatsApp.
6. Phone links use +234 915 085 9801, corresponding to 09150859801 in local Nigerian format.

CUSTOMISING THE LOGO
Open logo.svg in a code editor. Its bars and wordmark are vector shapes/text, so the colour and typography can be edited. If you want to use the uploaded logo image exactly, save that image in this folder as believers-digital-logo.png and change the img src in the header and home hero to that filename.

IMPORTANT
This is a static HTML/CSS/JavaScript website. The contact form does not store submissions in a database and there is no admin dashboard or online payment system included. WhatsApp is used for contact enquiries.
